# 题库规范

> 本文件是操作细则；`AGENTS.md` 只保留索引与硬约束。
> 改规则先改这里，再改实践。最后更新：<YYYY-MM-DD>

## 一、题型 / 章节表

| 编号 | 名称 | 分值 | 优先级 | 目录 | 单次题量 | 限时 | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |

> 题型制填题型，章节制填章节（与笔记目录同名）。单次题量与限时按本表执行。

## 二、标签体系

- 主标签：取自 `<笔记目录>` 的章节名，不新造
- 次标签：问法 / 陷阱类型（可选）
- 校验：标签必须能在来源文件中找到；新增标签先改笔记结构，再回填

## 三、整理

### 流程

```
登记来源 → 识别（OCR / 识图 / 文本提取）→ 结构化（≥20 题才用 JSON）
→ 校验 → 写 md → 归档原图 → 更新存量表
```

批量按批走：每批完成 → 校验 → 更新存量 → 再进下一批。

### 来源头

每个入库文件开头必须写全：

```markdown
> 来源等级：A ｜ 题源：<名称> ｜ 提取：YYYY-MM-DD ｜ 缺口：<无 / 说明>
```

等级默认判定：近年真题 A、早年真题 B、教辅（官方答案）C、教辅（AI 自答 / 待核）D、AI 生成 E。

### JSON 中间层（仅 ≥20 题）

- 字段：`id / type / topics / source / stem / options / answer / explain / assets / status`
- `status`：`verified`（官方 / 已核）或 `pending`（AI 自答、回忆版、OCR 存疑）
- 生命周期：识别 → JSON → 转 md → JSON 归档，不再维护；之后以 md 为唯一工作源

### md 模板（按题型）

| 题型 | 题目区 | 答案区 |
| --- | --- | --- |
| 改错 | 题号 + `#标签` + 题干（划线 `<u>…</u>(A)`） | 题号对齐，答案 + 改正 + 一句解析 |
| 阅读 | 按 Passage 分节：原文 → 5 题 | 按 Passage 分节，逐题答案 + 考点 |
| 完形 | 原文（空号 `(1)`）+ 逐题选项 | 逐题答案，可附考点标签 |
| 翻译 | 原句 → 译文 | 译文即答案，附考点 |
| 作文 | 题目 + 要求 | 官方范文 |
| 数学 | 题目（LaTeX） | 答案可单独文件（`答案/`） |

同一题型所有文件必须同构。

### 校验清单（每批必过）

| 项 | 判据 |
| --- | --- |
| 题号 | 连续，无跳号、无重号 |
| 答案 | 每题都有；缺失标 `[待补]` |
| 选项 | 数量正确（四选一 = 4 项） |
| 标签 | 必须存在于来源笔记文件，不新造 |
| 查重 | 重复题标注「与 `文件名#题号` 重复」，不静默合并 |
| 来源头 | 等级、题源、日期、缺口齐全 |

### 边界

1. **不虚构**：题目文本无法还原时，只留答案和考点方向，标 `[待补]`；
2. **AI 自答只做兜底**：官方答案缺失时才用，标 `[待核]`，不覆盖官方答案；
3. **重复题保留**：原始文件里的题不动，只加标注；抽题时按标注去重。

### 多 agent 并行

- 按章节 / 题型 / 文件分片，一个 agent 只写一个文件；
- 主 agent 先统一下发模板、标签表、命名规则；
- 子 agent 负责识图、写自己那份 md、自校；
- 主 agent 负责汇总、查重、标签合法性、来源头校验、更新存量；
- 默认 ≤4 个并行，避免限流。

### 归档

- 原图 / 关键识别页 → `<学科>/归档/<来源>/`，不删除；
- 处理中的临时文件放系统临时目录，完成后不留；
- 入库后更新题库 README 与 `刷题进度.md` 存量表。

## 四、剖析

- 触发：新题型首次整理完成后；新增 ≥2 套同题型真题；用户明确要求
- 范围：只统计 A/B 级真题；样本 < 20 题不做归纳
- 模板：`技巧笔记/命题归纳模板.md`（五节固定）
- 证据规则：每条结论必须能指向「年份 + 题号」；计数用真实统计，不精确到小数点；不确定标「约」
- 禁止项：正确答案 ABCD 分布、划线位置统计、把百分比当定律
- 更新：增量更新，保留旧结论并标注数据范围，更新日期

## 五、出题

### 模式

| 模式 | 触发 | 规则 |
| --- | --- | --- |
| 专项 | 「练 X 考点/章节」 | 按标签筛，A/B 优先，不足再 C |
| 混抽 | 「来一套」 | 按题型权重组卷，真题 ≥60% |
| 回炉 | 「回炉」 | 错 ≥2 次的标签优先，先重做再出新题 |
| 模考 | 「模考」 | 按真题卷面蓝图装配，见下 |

**模考蓝图**（来自真题剖析，不凭感觉）：

1. 题型结构：近 3–5 年真题卷面的题型顺序、题量、分值
2. 知识点分布：剖析的考点计数比例
3. 难度配比：送分 / 中等 / 陷阱
4. 问法覆盖：剖析的问法模板，每种至少 1 题
5. 限时：考试时长

题源不限（真题优先、教辅补充，需符合蓝图）；生成题默认不进模考。

### 选题顺序

```
标签筛 → 排除已抽 → 来源权重（A4 / B3 / C2 / D1 / E0.5）
→ 难度加权（辨析 / 直译 / 熟词僻义 / 陷阱优先；送分题 ≤20%）
→ 回炉插题（该标签错 ≥2 次）→ 凑足题量
```

- 已抽过的题不再抽（回炉除外）；抽完立即写入「抽题记录」
- 候选不足：先降级用 C；仍不足才允许生成题

### 题量与限时

按题型 / 章节表执行；每日默认 ≤2 套或 90 分钟。

### 输出

- 试卷 + 同名 md：试卷在前、答案在后；**不强制页数，题量优先，不刻意压缩**
- 排版可读性优先：字号、行距不低于基线
- 正面零提示（题号 + 题干 + 选项 / 划线），答案与考点只在答案部分
- 命名：`练习/YYYY-MM/<题型>-N题-YYYY-MM-DD.<ext>`
- 答案锚定最高等级；AI 自答标 `[待核]`，生成题标 `[AI生成]`

### 生成题

- 仅当题库某标签 < 10 题时允许
- 入 `题库/生成/`，标 `[AI生成]`
- 自检（答案唯一、可推导、无歧义、符合题型模板）+ 用户每批抽查 ≥1 题

## 六、批改

### 判分口径

- 锚定最高等级答案
- 客观题：答案 + 改正 / 步骤都对才得分（半对记 0.5）
- 翻译按踩分点；数学按步骤分
- AI 自答 / 生成题批改结果标「AI 判」

### 流程

```
用户自评 → 逐题判定 → 错因归类（四类 + 标签）
→ 知识点补漏 → 回炉入队 → 更新状态 → 出记录 + 精讲
```

- 先问「你觉得这题问题在哪」，再看答案
- 逐题判定表：题 / 你的答案 / 正确 / 判定 / 卡在哪
- 错因必须落到四类之一 + 一个标签，不写「粗心」

### 错因四类

| 类型 | 含义 | 对应动作 |
| --- | --- | --- |
| 不会 | 规则 / 词义确实缺 | 补笔记 + 专项 |
| 认错 | 会，但没识别出来 | 补判断入口 + 专项 |
| 写错 | 会也认得出，落笔错 | 检查清单 + 回炉 |
| 策略 | 审题 / 时间 / 空白 | 流程动作 + 限时训练 |

回炉队列按标签聚合；同一标签累计错 ≥2 次入队。

### 产出

- 练习记录 md：题目 + 作答 + 折叠答案；批改记录（判定表 / 错因 / 回炉清单）
- 精讲：判定表 + 错因 + 逐题精讲（错题详讲、对题一句带过）
- 速记卡：当天全部刷完后出，全量考点，每条四行

### 完成判据

每题有判定；错因 ≤4 类且落标签；补漏完成；回炉与掌握度已更新；记录、精讲齐全。

## 七、状态

- 文件：`题库/刷题进度.md`（schema 见文件头）
- 更新时机：抽题后、批改后
- 阈值：同一标签连续 2 次全对 → 降权；累计错 ≥2 次 → 进回炉队列
- 单次练习错题 ≥50% → 下调一档难度

## 八、复盘

- 每 5–10 套或每两周：复盘一次，刷新 `review_guidance`
- 每月：题库完整性 / 标签覆盖审计
- 复盘时先看 `刷题进度.md` 与错误集，再看是否偏离本规范
