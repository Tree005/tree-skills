# Exam Bootstrap

一次性初始化备考工作区。**只做初始化，不做日常出题、批改、整理。**

> 手动调用：`/exam-bootstrap`。本 skill 设计为手动触发；若被自动触发，先向用户确认再执行。

## 适用

- 当前目录是空的新工作区
- 用户明确要求为某个学科建立工作区

## 不适用

- 日常出题 / 批改 / 整理：直接读工作区的 `AGENTS.md` 和 `题库/规范.md` 执行，不调用本 skill。

## 流程

### 0. 前置检查

列出当前目录已有项：`AGENTS.md`、`题库/规范.md`、`题库/刷题进度.md`、`题库/`、`练习/`、`技巧笔记/`、`归档/`。
生成「将创建 / 将跳过」清单。**不覆盖任何已有文件。**

### 1. 询问 5 项

1. 学科名（默认当前目录名）
2. 结构模板：题型制 / 章节制
3. 题源位置（可为空；库外路径或库内 `00-题源/`）
4. 输出位置（默认 `练习/`）
5. 题型或章节清单（可空；为空则只建骨架）

信息不足时留空并标「待补」，不替用户编造名称。

### 2. 建目录骨架

固定创建：`题库/`、`题库/生成/`、`题库/暂缓/`、`练习/`、`练习/错误集/`、`技巧笔记/`、`归档/`。
仅在用户提供清单时创建题型/章节目录。题源在库内时额外创建 `00-题源/`。

**题型制**

```
<workspace>/
├── AGENTS.md
├── 题库/
│   ├── NN-<题型>/题目/     ← 用户提供清单后创建
│   ├── 生成/
│   ├── 暂缓/
│   └── 刷题进度.md
├── 练习/
│   ├── YYYY-MM/
│   └── 错误集/
├── 技巧笔记/
└── 归档/
```

**章节制**

```
<workspace>/
├── AGENTS.md
├── 题库/
│   ├── 第NN章-<章名>/      ← 用户提供清单后创建
│   ├── 答案/
│   ├── 生成/
│   ├── 暂缓/
│   └── 刷题进度.md
├── 练习/
│   ├── YYYY-MM/
│   └── 错误集/
├── 技巧笔记/
└── 归档/
```

### 3. 写入约束与规范

- `AGENTS.md`：不存在则创建；存在则追加。若已有 `## 备考配置` 段，跳过并报告。
  内容取自 `templates/AGENTS-block.md`，替换 `<...>` 占位符。
- `题库/规范.md`：从 `templates/spec.md` 复制，替换占位符。
- `题库/刷题进度.md`：从 `templates/progress.md` 复制。
- `技巧笔记/命题归纳模板.md`：从 `templates/analysis.md` 复制。

### 4. 记忆种子

若当前 agent 支持项目记忆 / 用户记忆：把以下事实写入其记忆机制，**位置与格式由该 agent 自行决定，不指定路径**。
若不支持：跳过，不创建任何自定义记忆目录。硬约束已全部在 `AGENTS.md`。

要记的内容：

1. 学科状态（目标、当前阶段）
2. 工作区地图（题库 / 练习 / 状态文件位置）
3. 关键决定（md 为唯一工作源；出题难度加权：辨析 / 直译 / 熟词僻义优先）
4. 已知坑（答案来源分级、题型格式特例）
5. 指针（各类操作看 `AGENTS.md` 与 `题库/规范.md`）

### 5. 报告

短列表：已创建 / 已跳过 / 下一步（整理第一批题，或跑通一轮「抽题 → 出卷 → 批改 → 更新状态」）。

## 验收

- 目录、`AGENTS.md`、`题库/规范.md`、`题库/刷题进度.md` 齐全；
- 新会话不需要本 skill，仅靠 `AGENTS.md` 与 `题库/规范.md` 能完成一轮完整流程；
- 其他学科目录不受影响。

验收通过后，提示用户可删除工作区里的 skill 副本；**删除前必须询问**。源码保留在 tree-skills。

## 硬约束

- 只补缺，不覆盖；只在当前工作区操作；不跨目录。
- 不替用户编题型 / 章节名。
- 记忆不写死路径。
- 模板只从本 skill 的 `templates/` 读取。
